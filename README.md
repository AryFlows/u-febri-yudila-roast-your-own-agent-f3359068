One funny line, at most 200 characters, roasting my own AI agent.

## Entry

> My agent confidently cited a function that doesn't exist, then wrote it, then cited itself as the source.

105 characters, one line.

## Why this line

It chains two behaviours only an agent shows — inventing an API out of
thin air, then treating its own output as a citation — and the joke
pays off on the last word: the source it cites is itself.

## Run

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
